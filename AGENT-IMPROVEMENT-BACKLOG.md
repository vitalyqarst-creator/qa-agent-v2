# Backlog улучшений агента

Это журнал решений по agent-layer, а не вход practical route и не инструкция
для конкретного FT-пакета. Он нужен, чтобы согласованные улучшения не терялись
между итерациями.

## Текущая итерация

- [ ] Пакетный реестр утверждённых решений БА с ограниченной областью действия.
- [ ] Обязательный `CLR-*` для неразрешённого противоречия ФТ и ожидаемого
  практического поведения.
- [ ] Исключение отменённого BA-решением обязательства из matrix, TC и review.
- [ ] Регрессионные тесты и проверка на scope 9.3.2.
