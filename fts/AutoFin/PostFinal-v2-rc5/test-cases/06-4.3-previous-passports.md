# 06-4.3-previous-passports

Controlled FT-first baseline для scope `4.3-previous-passports`.

Source basis: `PostFinal-v2-rc5`, раздел 4.3, таблица 4, блок `Данные предыдущих паспортов`, BSR 105-114. Source gate passed, source assertion review accepted for manifest digest `3b84b313d9747c4951924ac0298eb067d054b686e258e1241673b449264d53bc`. Current-passport artifacts used only as allowed analogy/reference; previous-passports FT remains authoritative.

Легенда статусов:

- `confirmed` - ожидаемый результат подтвержден source-first artifacts и пригоден для ручного FT-first выполнения.
- `candidate-ui-calibration` - правило/аналогия есть, но trigger, message или exact UI feedback нужно подтвердить перед automation-ready promotion.
- `blocked-observability` - без source/UI/fixture clarification нельзя честно утверждать точный observable expected result.
