## Общие предусловия для автоматизации

1. Открыть тестовый стенд AutoFin.
2. Авторизоваться пользователем, которому доступно создание/редактирование карточки заявки.
3. Открыть карточку заявки на route `#/application/card/create`, если в конкретном кейсе не указан другой setup.
4. Перейти к блоку `Участники`.
5. Для кейсов, которые требуют созданную строку участника, использовать setup profile `SETUP-PART-ROW-COBORROWER-001`.

## Reusable setup profiles

### SETUP-PART-BASE-001

1. Открыть новую карточку заявки на route `#/application/card/create`.
2. Перейти к блоку `Участники`.
3. Убедиться, что видны кнопки `Добавить созаемщика`, `Добавить залогодателя`, таблица участников и controls `EDIT`, `DELETE`.

### SETUP-PART-ROW-COBORROWER-001

1. Подготовить карточку заявки, в которой в таблице `Участники` есть одна строка участника.
2. Значения строки:
   - `Тип участия`: `Созаемщик`.
   - `ФИО`: `Иванов Иван Петрович`.
   - `Паспорт`: `4234 543534`.
   - `ID клиента`: пусто.
3. В UI pass эта строка была подготовлена вручную пользователем. Для автотеста нужно реализовать воспроизводимый setup через fixture/API/UI helper до запуска row-dependent кейсов.
