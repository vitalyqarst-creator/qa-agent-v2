# Тест-кейсы: 11-4.3 Документы по заявке

Save / persistence coverage plan: сохранение карточки заявки вне scope этого набора, потому что текущие ФТ/support/ответы БА не задают source-backed save action, save success oracle и повторное открытие; кейсы ниже проверяют только наблюдаемые UI-эффекты блока `Документы по заявке`.

## TC-DOC-001
**Название:** Блок «Документы по заявке» отображает информационную строку анкеты клиента
**Приоритет:** Medium
**Тип:** Positive
**package_id:** `WP-01`
**Трассировка:** `ATOM-003`; `ATOM-004`; `ATOM-054`; `ATOM-055`; `BSR 206`; `BSR 207`; `SRC-ROW-003`
**Сценарное обоснование:** Связанные `ATOM-*` и `BSR` описывают один проверяемый UI-элемент и один ожидаемый результат этого TC.

**Цель:** Проверить видимость и информационный характер строки про анкету клиента.

**Предусловия:**
1. Открыть карточку заявки.
2. Перейти к блоку `Документы по заявке`.

**Тестовые данные:**
- Не требуются.

**Шаги:**
1. Осмотреть строку `Анкета клиента. Распечатайте, подпишите с клиентом и загрузите скан в заявку`.

**Итоговый ожидаемый результат:** В блоке отображается строка `Анкета клиента. Распечатайте, подпишите с клиентом и загрузите скан в заявку`; строка представлена как текстовая информационная строка и не предоставляет пользователю действие редактирования.

**Постусловия:**

**Постусловия:**
- Очистить поле `Дата выдачи`.
