# 10-4.3-additional-client-info

Controlled FT-first baseline для scope `4.3-additional-client-info`.

Source basis: `PostFinal-v2-rc5`, раздел 4.3, таблица 4, блок `Дополнительная информация`, BSR 190-205. Source assertion review принят для manifest digest `f1ea6534e6b9001ceb6b9ad65026c4b195283adcccb599b842a0cd05cca823bd`. Для проверок со статусами `candidate-ui-calibration` и `blocked-observability` production promotion не заявляется.

Легенда статусов:

- `confirmed` - ожидаемый результат подтвержден source-first artifacts и пригоден для ручного FT-first выполнения.
- `candidate-ui-calibration` - ФТ подтверждает правило, но точный validation trigger или UI feedback нужно откалибровать в UI перед automation-ready promotion.
- `blocked-observability` - ФТ подтверждает integration-dependent behavior, но точный fixture/result observation зависит от внешних integration details, отсутствующих в текущем scope.

## Вопросы Для UI-Калибровки

- `GAP-ADDINFO-INN-INTEGRATION-001`: нужны source-approved fixtures и наблюдаемые ожидаемые результаты для успешного поиска ИНН, неуспешной верификации ИНН, недоступной интеграции, обновления чек-бокса и блокировки персональных/паспортных полей после `ИНН проверен = Да`.
- `GAP-ADDINFO-REQUIREDNESS-TRIGGER-001`: нужен validation trigger и точный UI feedback для обязательных полей `ИНН клиента`, `Состоите ли вы в зарегистрированном браке?` и `Количество иждивенцев`.
