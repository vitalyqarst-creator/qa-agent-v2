# UI calibration results

Сохраняй сюда результаты прохождения на стенде.

Рекомендуемый формат имени файла:

```text
<TC-ID>.md
```

Например:

```text
TC-CP-6560C2E054.md
```

Не коммить секреты, пароли, персональные данные клиентов или скриншоты с чувствительными данными без отдельного разрешения.
