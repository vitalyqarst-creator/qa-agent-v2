# Расшифровка колонок `О` и `Р`

Уточнение по таблицам ФТ Partners-v1, предоставленное для работы с пакетом.

| Колонка | Значение |
| --- | --- |
| `О` | Обязательность заполнения поля. `Да` — поле должно быть заполнено; `Нет` — поле необязательно. Условие в ячейке определяет, когда действует обязательность. |
| `Р` | Редактируемость поля. `Да` — значение можно редактировать; `Нет` — редактирование недоступно. Условие в ячейке определяет, когда действует редактируемость. |

Эти колонки сами по себе не задают формат, допустимые значения, текст сообщения или способ валидации. Такие детали следует брать только из соответствующей строки ФТ, подтверждённого ответа БА или UI-калибровки.
