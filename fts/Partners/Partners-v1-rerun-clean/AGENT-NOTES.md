# Partners-v1 — чистый повторный прогон

## Граница работы

Работай только в данном пакете:

```text
fts/Partners/Partners-v1-rerun-clean
```

Это чистый повторный прогон practical route для scope `9.3.2` «Карточка
партнёра». Не используй work-артефакты, matrix, test-cases или выводы
предыдущих прогонов как входные требования либо результат review.

## Уточнения БА

Утверждённые решения БА намеренно отсутствуют на старте этого прогона. При
неоднозначности сначала зафиксируй вопрос в
`scope-clarification-requests.md`. После этого контролёр передаст
соответствующие утверждённые ответы как support-вход и свяжет их с `GAP-*`.
Не используй сведения из прежних прогонов как требования без добавленного
источника.
