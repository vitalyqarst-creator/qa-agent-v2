# Утверждённые решения БА — Partners-v1

## BA-DEC-001 — Фактический адрес в карточке партнёра

```yaml
decision_id: "BA-DEC-001"
status: "approved"
authority: "business-analyst"
decision_type: "supersedes-ft"
applies_to: "Весь FT-пакет Partners-v1; только карточка партнёра. Не распространяется на карточку реквизита и иные объекты без отдельного решения БА."
requirement_refs: "Раздел 9.3.2, AS.34; таблица 6, правила автозаполнения по наименованию партнёра и ИНН."
decision: "Поля «Фактический адрес» в карточке партнёра не будет. Не проектировать и не писать тест-кейсы на наличие, автоматическое заполнение, редактирование или сохранение этого поля."
```

**Источник ответа:** подтверждённый ответ бизнес-аналитика, переданный
пользователем.

## BA-DEC-002 — обязательные поля карточки партнёра

```yaml
decision_id: "BA-DEC-002"
status: "approved"
authority: "business-analyst"
decision_type: "clarifies-ft"
applies_to: "Весь FT-пакет Partners-v1; карточка партнёра и карточка реквизита для строк таблиц ФТ с О=Да."
requirement_refs: "Таблица 6 и Таблица 8, колонка О."
decision: "При незаполненном обязательном поле используется стандартная валидация платформы с красной подсветкой; сохранение не выполняется."
```

**Источник ответа:** «Стандартная валидация платформы с подсвечиванием
красным. Сохранение не выполняется с любым не заполненным обязательным
полем.», подтверждённый ответ бизнес-аналитика, переданный пользователем.

## BA-DEC-003 — ключ проверки дубликата партнёра

```yaml
decision_id: "BA-DEC-003"
status: "approved"
authority: "business-analyst"
decision_type: "clarifies-ft"
applies_to: "Весь FT-пакет Partners-v1; проверка дубликата в карточке партнёра."
requirement_refs: "AS.5, AS.36–AS.38; Таблица 7."
decision: "Дубликат партнёра определяется совпадением пары «Наименование партнёра» и «ИНН»."
```

**Источник ответа:** «Проверка дубля партнера — по Наименованию + ИНН»,
подтверждённый ответ бизнес-аналитика, переданный пользователем.
