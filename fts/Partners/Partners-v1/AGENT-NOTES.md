# Partners-v1 — контекст пакета

## Граница работы

Работай только в данном пакете, если пользователь явно не указал другой:

```text
fts/Partners/Partners-v1
```

## Исходники ФТ

- `source/Final-FR-9-Partners.docx` — источник смысла требований;
- `source/Final-FR-9-Partners.xhtml` — обязательный машиночитаемый источник;
- `source/Final-FR-9-Partners.pdf` — структурная и визуальная сверка.

## Доступный контекст

- `support/PAB_справочники_выгрузка_v2.md` — статический справочник проекта;
- `support/partners-v1-table-column-legend.md` — расшифровка колонок ФТ;
- `support/spravochnik_gorodov_only_names.md` — переданный пользователем
  перечень городов для выбора конкретных тестовых значений;
- `support/figma/figma-design-index.md` — ссылка на необязательный визуальный источник;
- `mockups/` — макеты для уточнения наблюдаемых UI-шагов.

Макеты и Figma помогают описывать интерфейс, но не заменяют текст ФТ и не задают бизнес-правила.

## Уточнения БА и дополнительные данные

При отсутствии ответа по конкретному утверждению ФТ сначала зафиксируй вопрос в
`scope-clarification-requests.md`; после ответа контролёр добавит материал как
scope-local support или в реестр утверждённых решений БА и свяжет его с
соответствующими `GAP-*`.

Не используй сведения из предыдущих прогонов как требования без добавленного и привязанного источника.
