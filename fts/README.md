# Локальные FT-пакеты

Каждый прогон создаётся здесь из чистого шаблона и содержит только материалы конкретного ФТ:

- `source/` — DOCX, обязательный XHTML и PDF;
- `support/` — относящиеся к этому ФТ справочники и утверждённые ответы БА;
- `mockups/` — приложенные макеты;
- `AGENT-NOTES.md` — краткий контекст пакета;
- `work/` — matrix, вопросы к БА и каталоги fixtures текущего прогона;
- `test-cases/` — только выпущенные TC текущего пакета.

Не копируй в пакет `evals`, benchmark, результаты других ФТ, архивы старых запусков и исходный код runtime. Каждый пакет создаётся пустым до добавления собственных источников.
